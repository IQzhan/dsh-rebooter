# 状态面板 — 设计说明

本文是 **DSH Server** 状态面板的规范原文英文版见 [`status-panel.md`](status-panel.md)。

## 要解决什么

不打开 DSH 聊天界面，也能看见开启服务 / 关闭服务 / 重启服务 / 更新插件 / 更新 DSH / 打开界面的进度；一个桌面入口 **DSH Server**；关掉或最小化面板**绝不**影响 DSH 与监督进程。

## 明确不做（已丢弃）

- 五个独立桌面启动器 → 改由一个面板聚合。
- 空闲时也常驻整页控制台 → 只在任务进行中（或失败后）显示日志。
- 开启服务后默认打开浏览器 → 默认关；勾选「开启服务时打开界面」或按「打开界面」。
- 面板进程托管 DSH 生命周期 → 面板只负责展示与派发 CLI。
- 全平台完美「已打开则仅虚焦并刷新」→ 尽力而为。

## 结构（解耦）

状态全在 `$DSH_HOME/rebooter/` 的文件里（`job.json` / `job.log` / `panel.json`）。  
面板是本机 HTTP（`webPort + 10001`）+ 极简 HTML。  
真正干活的仍是现有 `performAction` / supervisor。  
窗口壳与桌面快捷方式按系统生成（`package/panel/`，桌面名 **DSH Server**）。  
可选的 Win32 标题栏拖拽 helper 只给 **DSH 页面**窗口用；面板始终走可移植的屏幕位移拖拽。

## 按钮（稳定态）

面板先画服务按钮，再画两个带标题的分组（**插件** / **DSH**）。禁止单独写「更新」。

| 状态 | 服务 | 插件 | DSH |
| --- | --- | --- | --- |
| 服务未开 | 开启服务 | 更新插件 · 更新插件并开启服务 | 更新 DSH · 更新 DSH 并开启服务 |
| 服务已开 | 关闭服务 · 重启服务 | 更新插件并关闭服务 · 更新插件并重启服务 | 更新 DSH 并关闭服务 · 更新 DSH 并重启服务 |

「打开界面」仍在下方打开行，不进这两组。  
忙碌时（`job.state === busy`）隐藏全部操作按钮，只留状态条 + 日志。  
页面窗口的电源按钮弹出同样四项**插件**生命周期（DSH 已在跑）；DSH 本体升级只在面板与 CLI。点选后也会自动唤起面板看进度。

## 进度与日志

- 始终有状态条（文案 + 忙碌时转圈）。
- 日志只在忙碌时出现；失败后保留到下一次空闲操作；成功空闲则收起。
- 插件 / DSH 更新若中途失败，会先回滚到发起前状态；`…并重启服务` 仍会尝试拉起服务，状态条显示失败原因。
- 关掉再开面板，进度与日志从文件恢复，无需手动刷新。

## 打开界面

「打开界面」在独立窗口打开 DSH 页面（默认不是系统浏览器）。齿轮绑定程序后优先开那个程序；「开启服务时打开界面」写入 `panel.json`，默认关。

**DSH 页面窗口：** 无系统标题栏；右上角 L 形热区悬停出现电源 / 最小化 / 最大化 / 关闭。顶部空白可拖动；Windows 走系统标题栏移动（Aero Snap），其它平台用屏幕位移。双击顶部空白 = 最大化/还原按钮（同一条 `max`）。最大化图标只跟真实窗口状态。

**DSH Server 面板：** 自绘顶栏（仅最小化 / 关闭），自定义拖拽，不停靠、不改鼠标样式。颜色跟 DSH 网页令牌；文案/皮肤读 profile 的 `cordis.patch.yml`（没有 patch 才回退 `settings.yaml`）。动作按钮在轮询间保持稳定，避免点击被吞。

关服务会关页面窗口；窗口自己的关闭只关窗口。

## 生成入口

`dsh-rebooter desktop` 以及面板上的「放到桌面」会重新写桌面快捷方式。入口文件 `DSH-Server.vbs` 和 `DSH-Server.sh` 随包装发布，用自身位置找到 `lib/cli.cjs`，不写死本机路径。桌面快捷方式只在第一次 Host 挂载成功时创建；删掉后不会因为再次启动而回来。桌面入口名为 **DSH Server**：Windows 快捷方式图标是内嵌官方 DeepSeek 标志的 `dsh-server.ico`，Linux 用 `dsh-server.png`，macOS 是 `.app`（不留终端）。窗口组件起不来时，DSH Server 和 DSH 页面改由系统默认方式打开。文案只有 `zh` / `en` 两套，匹配方式与 DSH 相同。写快捷方式的临时文件不放在桌面。窗口宿主装在插件自己的 `node_modules` 里，需要 `Node 24`。换机器执行构建即可。
