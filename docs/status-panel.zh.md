# 状态面板 — 设计说明

本文是 **DSH Server** 状态面板的规范原文英文版见 [`status-panel.md`](status-panel.md)。

## 要解决什么

不打开 DSH 聊天界面，也能看见开启服务 / 关闭服务 / 重启服务 / 更新 / 打开界面的进度；一个桌面入口 **DSH Server**；关掉或最小化面板**绝不**影响 DSH 与监督进程。

## 明确不做（已丢弃）

- 五个独立桌面启动器 → 改由一个面板聚合。
- 空闲时也常驻整页控制台 → 只在任务进行中（或失败后）显示日志。
- 开启服务后默认打开浏览器 → 默认关；勾选「开启服务时打开界面」或按「打开界面」。
- 面板进程托管 DSH 生命周期 → 面板只负责展示与派发 CLI。
- 全平台完美「已打开则仅虚焦并刷新」→ 尽力而为。

## 结构（解耦）

状态全在 `$DSH_HOME/rebooter/` 的文件里（`job.json` / `job.log` / `panel.json`）。  
面板是本机 HTTP（`webPort + 10001`）+ 极简 HTML。  
真正干活的仍是现有 `performAction` / supervisor。  
只有窗口壳与桌面快捷方式按系统生成，落在 `package/panel/`，桌面快捷方式名称为 **DSH Server**。

## 按钮（稳定态）

| 状态 | 按钮 |
| --- | --- |
| 服务未开 | 开启服务 · 更新 · 更新并开启服务 |
| 服务已开 | 关闭服务 · 重启服务 · 更新并关闭服务 · 更新并重启服务 · 打开界面 |

忙碌时（`job.state === busy`）隐藏全部操作按钮，只留状态条 + 日志。  
页面窗口的电源按钮弹出同样四项（DSH 已在跑）；点选后也会自动唤起面板看进度。

## 进度与日志

- 始终有状态条（文案 + 忙碌时转圈）。
- 日志只在忙碌时出现；失败后保留到下一次空闲操作；成功空闲则收起。
- 关掉再开面板，进度与日志从文件恢复，无需手动刷新。

## 打开界面

「打开界面」在独立窗口里打开 DSH 页面，不再默认交给系统浏览器。点齿轮后在下方输入路径，或用「浏览」弹出系统文件选择器；确定后齿轮变为「清除」，已绑定的程序仍然优先。勾选「开启服务时打开界面」写入 `panel.json`。开启服务默认不打开界面。窗口高度随内容变化，空闲时不预留日志空白。独立窗口没有系统标题栏，任务栏图标用官方 DSH 标志。右上角贴边的一横一竖细条悬停时出现一块实心操作栏：两条都大约 12 像素粗，长度大约与操作栏一样宽。电源、最小化、最大化、关闭，移开就隐藏。电源按钮弹出四项菜单，不会一点就停。顶部没有交互的空白可以拖动窗口，不铺遮罩。DSH Server 仍用内建顶栏，只有最小化和关闭，拖拽走同一套屏幕位移。面板颜色跟 DSH 网页令牌走，并跟随系统浅色/深色。文案在 `locale.preference` 未设置时按浏览器语言列表匹配，否则用 `$DSH_HOME/settings.yaml` 里的选择。皮肤读同一文件的 `ui-theme.preference`（`light` / `dark` / `system`），随快照刷新。关闭服务会关掉界面窗口。窗口上的关闭只关窗口。

## 生成入口

`dsh-rebooter desktop` 以及面板上的「放到桌面」会重新写桌面快捷方式。入口文件 `DSH-Server.vbs` 和 `DSH-Server.sh` 随包装发布，用自身位置找到 `lib/cli.cjs`，不写死本机路径。桌面快捷方式只在第一次 Host 挂载成功时创建；删掉后不会因为再次启动而回来。桌面入口名为 **DSH Server**：Windows 快捷方式图标是内嵌官方 DeepSeek 标志的 `dsh-server.ico`，Linux 用 `dsh-server.png`，macOS 是 `.app`（不留终端）。窗口组件起不来时，DSH Server 和 DSH 页面改由系统默认方式打开。文案只有 `zh` / `en` 两套，匹配方式与 DSH 相同。写快捷方式的临时文件不放在桌面。窗口宿主装在插件自己的 `node_modules` 里，需要 `Node 24`。换机器执行构建即可。
